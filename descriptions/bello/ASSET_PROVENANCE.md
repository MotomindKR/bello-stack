# Bello asset provenance

This directory is the canonical source for Bello robot descriptions in
`MotomindKR/bello-stack`. The full-body URDF composes the lower- and upper-body
meshes stored beside it; downstream repositories consume a pinned Git commit
and should not maintain independent copies.

The descriptions and meshes are proprietary. This repository does not grant
permission to redistribute them. External distribution requires a separate
written agreement with the applicable rights holder.
